# 设备挂载监听与树视图控制

## 需求背景

在文件管理器的侧边栏中，需要实现对设备（如U盘、移动硬盘等）的挂载和卸载进行监听，并相应地更新树视图的状态。主要涉及两个方面：

1. 设备挂载时：需要刷新 finalUrl 属性，使设备可以被双击展开
2. 设备卸载时：需要清理已展开的子树，并清理 finalUrl 字段

此外，还需要实现对文件夹增删的监听，使得在侧边栏上能够同步看到目录下文件夹的增删效果。

## 技术方案

### 1. 利用现有实现

`dfmplugin-computer` 插件中的 `ComputerItemWatcher` 类已经实现了设备状态监听和侧边栏更新的基础功能。在 `onUpdateBlockItem` 函数中，我们可以直接获取设备的 URL 信息：

```cpp
void ComputerItemWatcher::onUpdateBlockItem(const QString &id)
{
    QUrl &&devUrl = ComputerUtils::makeBlockDevUrl(id);
    Q_EMIT this->itemUpdated(devUrl);
    auto ret = std::find_if(initedDatas.cbegin(), initedDatas.cend(), 
        [devUrl](const ComputerItemData &data) { return data.url == devUrl; });
    if (ret != initedDatas.cend()) {
        auto item = initedDatas.at(ret - initedDatas.cbegin());
        if (item.info) {
            item.info->refresh();
            // 从 item.info 中获取设备的 URL 信息
            QUrl finalUrl = item.info->targetUrl();  // 或者使用其他合适的 URL 获取方法
            updateSidebarItem(devUrl, item.info->displayName(), item.info->renamable(), finalUrl);
        }
    }
}
```

### 3. 文件夹增删监听实现

#### 3.1 创建专门的监听类

我们可以创建一个专门的监听类 `SidebarFileWatcher`，用于处理文件系统的监听：

```cpp
// sidebarfilewatcher.h
class SidebarFileWatcher : public QObject
{
    Q_OBJECT
public:
    explicit SidebarFileWatcher(QObject *parent = nullptr);
    ~SidebarFileWatcher();

    void watchDirectory(const QUrl &url);
    void unwatchDirectory(const QUrl &url);
    void stopAllWatchers();

signals:
    void directoryCreated(const QUrl &parentUrl, const QUrl &url);
    void directoryRemoved(const QUrl &parentUrl, const QUrl &url);

private slots:
    void onSubfileCreated(const QUrl &parentUrl, const QUrl &url);
    void onFileDeleted(const QUrl &parentUrl, const QUrl &url);

private:
    QMap<QUrl, LocalFileWatcher*> watchers;
};
```

```cpp
// sidebarfilewatcher.cpp
SidebarFileWatcher::SidebarFileWatcher(QObject *parent)
    : QObject(parent)
{
}

SidebarFileWatcher::~SidebarFileWatcher()
{
    stopAllWatchers();
}

void SidebarFileWatcher::watchDirectory(const QUrl &url)
{
    if (url.isValid() && url.isLocalFile() && !watchers.contains(url)) {
        auto watcher = new LocalFileWatcher(url, this);
        connect(watcher, &LocalFileWatcher::subfileCreated, this, &SidebarFileWatcher::onSubfileCreated);
        connect(watcher, &LocalFileWatcher::fileDeleted, this, &SidebarFileWatcher::onFileDeleted);
        watcher->startWatcher();
        watchers.insert(url, watcher);
    }
}

void SidebarFileWatcher::unwatchDirectory(const QUrl &url)
{
    if (watchers.contains(url)) {
        auto watcher = watchers.take(url);
        watcher->stopWatcher();
        watcher->deleteLater();
    }
}

void SidebarFileWatcher::onSubfileCreated(const QUrl &parentUrl, const QUrl &url)
{
    // 检查是否是目录
    QFileInfo fileInfo(url.toLocalFile());
    if (fileInfo.isDir()) {
        emit directoryCreated(parentUrl, url);
    }
}

void SidebarFileWatcher::onFileDeleted(const QUrl &parentUrl, const QUrl &url)
{
    emit directoryRemoved(parentUrl, url);
}
```

#### 3.2 在 TreeModel 中使用监听类

在 `TreeModel` 类中使用 `SidebarFileWatcher` 来处理文件监听：

```cpp
// treemodel.h
class TreeModel : public QAbstractItemModel
{
    // ...
private:
    SidebarFileWatcher *fileWatcher;
    QSet<QUrl> expandedUrls;
    
private slots:
    void onDirectoryCreated(const QUrl &parentUrl, const QUrl &url);
    void onDirectoryRemoved(const QUrl &parentUrl, const QUrl &url);
};
```

```cpp
// treemodel.cpp
TreeModel::TreeModel(QObject *parent)
    : QAbstractItemModel(parent)
{
    fileWatcher = new SidebarFileWatcher(this);
    connect(fileWatcher, &SidebarFileWatcher::directoryCreated, this, &TreeModel::onDirectoryCreated);
    connect(fileWatcher, &SidebarFileWatcher::directoryRemoved, this, &TreeModel::onDirectoryRemoved);
}

void TreeModel::onItemExpanded(const QModelIndex &index)
{
    QUrl url = data(index, SidebarItem::kUrlRole).toUrl();
    if (url.isValid() && url.isLocalFile()) {
        expandedUrls.insert(url);
        fileWatcher->watchDirectory(url);
    }
}

void TreeModel::onItemCollapsed(const QModelIndex &index)
{
    QUrl url = data(index, SidebarItem::kUrlRole).toUrl();
    if (url.isValid()) {
        expandedUrls.remove(url);
        fileWatcher->unwatchDirectory(url);
    }
}

void TreeModel::onDirectoryCreated(const QUrl &parentUrl, const QUrl &url)
{
    // 在树视图中添加新目录
    QModelIndex parentIndex = findIndexByUrl(parentUrl);
    if (parentIndex.isValid()) {
        // 创建新的侧边栏项
        QVariantMap data = createSidebarItemData(url);
        addItemToModel(parentIndex, data);
    }
}

void TreeModel::onDirectoryRemoved(const QUrl &parentUrl, const QUrl &url)
{
    // 在树视图中移除目录
    QModelIndex index = findIndexByUrl(url);
    if (index.isValid()) {
        // 移除侧边栏项
        removeItemFromModel(index);
    }
}
```

#### 3.3 优化监听机制

为了避免为每个展开的目录都创建一个监听器，可以考虑使用一个全局的监听器，并维护一个展开目录的列表：

```cpp
// sidebarfilewatcher.h
class SidebarFileWatcher : public QObject
{
    // ...
private:
    LocalFileWatcher *globalWatcher;
    QSet<QUrl> watchedUrls;
    
private slots:
    void onGlobalSubfileCreated(const QUrl &parentUrl, const QUrl &url);
    void onGlobalFileDeleted(const QUrl &parentUrl, const QUrl &url);
};
```

```cpp
// sidebarfilewatcher.cpp
SidebarFileWatcher::SidebarFileWatcher(QObject *parent)
    : QObject(parent)
{
    // 创建一个全局的文件监听器
    globalWatcher = new LocalFileWatcher(QUrl::fromLocalFile("/"), this);
    connect(globalWatcher, &LocalFileWatcher::subfileCreated, this, &SidebarFileWatcher::onGlobalSubfileCreated);
    connect(globalWatcher, &LocalFileWatcher::fileDeleted, this, &SidebarFileWatcher::onGlobalFileDeleted);
    globalWatcher->startWatcher();
}

void SidebarFileWatcher::watchDirectory(const QUrl &url)
{
    if (url.isValid() && url.isLocalFile()) {
        watchedUrls.insert(url);
    }
}

void SidebarFileWatcher::unwatchDirectory(const QUrl &url)
{
    watchedUrls.remove(url);
}

void SidebarFileWatcher::onGlobalSubfileCreated(const QUrl &parentUrl, const QUrl &url)
{
    // 检查父目录是否在监听列表中
    if (watchedUrls.contains(parentUrl)) {
        // 检查是否是目录
        QFileInfo fileInfo(url.toLocalFile());
        if (fileInfo.isDir()) {
            emit directoryCreated(parentUrl, url);
        }
    }
}

void SidebarFileWatcher::onGlobalFileDeleted(const QUrl &parentUrl, const QUrl &url)
{
    // 检查父目录是否在监听列表中
    if (watchedUrls.contains(parentUrl)) {
        emit directoryRemoved(parentUrl, url);
    }
}
```

## 注意事项

1. 状态同步
   - 确保设备状态变化时，finalUrl 及时更新
   - 保持树视图状态的一致性

2. 错误处理
   - 处理设备访问权限问题
   - 处理设备异常卸载情况

3. 用户体验
   - 设备状态变化时提供适当的视觉反馈
   - 保持树视图的展开状态一致性

4. 性能考虑
   - 文件监听可能会消耗较多系统资源，需要合理管理监听器的生命周期
   - 考虑使用批量更新机制，避免频繁刷新界面
