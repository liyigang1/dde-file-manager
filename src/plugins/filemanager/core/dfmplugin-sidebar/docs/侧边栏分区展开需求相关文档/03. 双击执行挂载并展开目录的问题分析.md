# 双击执行挂载并展开目录的问题分析

## 问题描述
当前在侧边栏分区子项上，单击可以执行挂载，双击也可以执行挂载。但是存在一个问题：当双击时，虽然执行了挂载动作，但挂载目录还未同步到侧边栏子项中，此时无法展开目录列表。用户必须等到信号过来更新侧边栏后，才能再次点击展开子项。

期望优化：双击执行挂载的同时，也能够直接展开目录列表，无需等待。

## 问题原因分析

通过阅读代码和提交历史，可以理解当前的工作流程：

1. 在 `dfmplugin-computer` 插件中，`ComputerItemWatcher` 类负责监听设备挂载事件：
   ```cpp
   void ComputerItemWatcher::onBlockDeviceMounted(const QString &id, const QString &mntPath)
   {
       Q_UNUSED(mntPath);
       auto &&datas = DevProxyMng->queryBlockInfo(id);
       auto shellDevId = datas.value(GlobalServerDefines::DeviceProperty::kCryptoBackingDevice).toString();
       onUpdateBlockItem(shellDevId.length() > 1 ? shellDevId : id);
   }
   ```

2. 当设备挂载后，`onUpdateBlockItem` 方法会从设备信息中获取 `finalUrl`，并通过信号更新侧边栏：
   ```cpp
   void ComputerItemWatcher::onUpdateBlockItem(const QString &id)
   {
       QUrl &&devUrl = ComputerUtils::makeBlockDevUrl(id);
       Q_EMIT this->itemUpdated(devUrl);
       auto ret = std::find_if(initedDatas.cbegin(), initedDatas.cend(), 
           [devUrl](const ComputerItemData &data) { return data.url == devUrl; });
       if (ret != initedDatas.cend()) {
           auto item = initedDatas.at(ret - initedDatas.cbegin());
           if (item.info) {
               item.info->refresh();
               // 获取设备的 URL 信息
               QUrl finalUrl = item.info->targetUrl();
               updateSidebarItem(devUrl, item.info->displayName(), item.info->renamable(), finalUrl);
           }
       }
   }
   ```

3. `updateSidebarItem` 方法通过 DPF 框架发送信号到侧边栏插件：
   ```cpp
   void ComputerItemWatcher::updateSidebarItem(const QUrl &url, const QString &newName, bool editable, const QUrl &finalUrl)
   {
       QVariantMap map {
           { "Property_Key_DisplayName", newName },
           { "Property_Key_Editable", editable },
           { "Property_Key_FinalUrl", finalUrl }  // 添加 finalUrl 更新
       };
       dpfSlotChannel->push("dfmplugin_sidebar", "slot_Item_Update", url, map);
   }
   ```

4. 在侧边栏插件中，当双击分区项时，`SideBarViewPrivate::onItemDoubleClicked` 会调用 `expandPartitionItem` 方法：
   ```cpp
   void SideBarViewPrivate::onItemDoubleClicked(const QModelIndex &index)
   {
       if (!index.isValid())
           return;
       
       SideBarItem *item = q->model()->itemFromIndex(index);
       
       // 处理分组项展开/折叠
       if (dynamic_cast<SideBarItemSeparator *>(item)) {
           q->onChangeExpandState(index, !q->isExpanded(index));
           return;
       }
       
       // 处理分区项展开子文件夹
       if (item && item->group() == DefaultGroup::kDevice) {
           // 获取分区路径
           QUrl url = item->targetUrl();  // 这里使用 targetUrl()
           
           // 判断是否为本地文件路径
           if (url.scheme() != "file")
               return;
               
           // 展开子文件夹
           expandPartitionItem(index, url);
           return;
       }
   }
   ```

5. 问题的关键在于，在双击触发挂载后，`targetUrl()` 还未更新，此时无法获取正确的挂载路径。而 `finalUrl` 的更新是异步的，需要等待 `slot_Item_Update` 信号处理后才会更新到 `ItemInfo` 中：
   ```cpp
   QUrl SideBarItem::targetUrl() const
   {
       QUrl targetItemUrl;
       if (!itemInfo().finalUrl.isEmpty())
           targetItemUrl = itemInfo().finalUrl;
       else
           targetItemUrl = url();
       return targetItemUrl;
   }
   ```

## 解决方案

### 方案一：利用 SideBarEventReceiver 现有机制（不推荐）

此方案有违背单一职责原则的问题，让计算机插件负责侧边栏的展开逻辑不是一个良好的设计。

### 方案二：在 SideBarViewPrivate 中添加待展开项的管理

修改 `SideBarViewPrivate` 类，增加静态成员来存储待展开的项：

```cpp
// 在 sidebarview_p.h 中
class SideBarViewPrivate : public QObject
{
    // ... 原有代码 ...
    
public:
    // 用于挂载后自动展开的静态成员
    static QUrl pendingExpandUrl;
    static QModelIndex pendingExpandIndex;
    
    // ... 原有代码 ...
};
```

在 `sidebarview.cpp` 中实现这些静态成员：

```cpp
QUrl SideBarViewPrivate::pendingExpandUrl;
QModelIndex SideBarViewPrivate::pendingExpandIndex;
```

修改 `SideBarViewPrivate::onItemDoubleClicked` 方法：

```cpp
void SideBarViewPrivate::onItemDoubleClicked(const QModelIndex &index)
{
    if (!index.isValid())
        return;
    
    SideBarItem *item = q->model()->itemFromIndex(index);
    
    // 处理分组项展开/折叠
    if (dynamic_cast<SideBarItemSeparator *>(item)) {
        q->onChangeExpandState(index, !q->isExpanded(index));
        return;
    }
    
    // 处理分区项展开子文件夹
    if (item && item->group() == DefaultGroup::kDevice) {
        // 获取分区路径
        QUrl url = item->targetUrl();
        QUrl originalUrl = item->url();
        
        // 判断设备是否已挂载
        bool deviceMounted = !url.isEmpty() && url.isValid() && 
                            url.scheme() == "file" && 
                            QDir(url.path()).exists();
        
        if (deviceMounted) {
            // 设备已挂载，直接展开
            expandPartitionItem(index, url);
        } else {
            // 设备未挂载，先设置待展开的URL和索引
            // 原有代码会处理挂载请求
            pendingExpandUrl = originalUrl;
            pendingExpandIndex = index;
        }
        return;
    }
}
```

### 方案三：在 SideBarEventReceiver 中扩展 handleItemUpdate 方法（推荐方案）

在侧边栏插件的 `SideBarEventReceiver` 类中已有处理 `slot_Item_Update` 事件的方法，可以扩展这个方法来实现自动展开：

```cpp
bool SideBarEventReceiver::handleItemUpdate(const QUrl &url, const QVariantMap &properties)
{
    if (!SideBarInfoCacheMananger::instance()->contains(url))
        return false;

    ItemInfo info { SideBarInfoCacheMananger::instance()->itemInfo(url) };
    
    // 处理原有的更新逻辑
    // ... 原有代码 ...
    
    // 检查是否需要展开挂载的设备
    if (properties.contains(PropertyKey::kFinalUrl)) {
        QUrl finalUrl = properties[PropertyKey::kFinalUrl].toUrl();
        if (finalUrl.isValid() && finalUrl.scheme() == "file" && 
            SideBarViewPrivate::pendingExpandUrl == url && 
            SideBarViewPrivate::pendingExpandIndex.isValid()) {
            
            // 延迟展开以确保设备已完全挂载
            QTimer::singleShot(100, [url, finalUrl]() {
                // 找到所有侧边栏实例
                QList<SideBarWidget *> allSideBar = SideBarHelper::allSideBar();
                for (SideBarWidget *sidebar : allSideBar) {
                    if (!sidebar) continue;
                    
                    // 获取视图和其私有成员
                    SideBarView *view = qobject_cast<SideBarView *>(sidebar->view());
                    if (!view || !view->d) continue;
                    
                    // 获取当前项并展开
                    SideBarItem *item = view->model()->itemFromIndex(
                        SideBarViewPrivate::pendingExpandIndex);
                    if (!item) continue;
                    
                    // 获取最新的目标URL并展开
                    QUrl mountedUrl = item->targetUrl();
                    if (mountedUrl.isValid() && QDir(mountedUrl.path()).exists())
                        view->d->expandPartitionItem(
                            SideBarViewPrivate::pendingExpandIndex, mountedUrl);
                }
                
                // 清除待处理的URL和索引
                SideBarViewPrivate::pendingExpandUrl = QUrl();
                SideBarViewPrivate::pendingExpandIndex = QModelIndex();
            });
        }
    }
    
    // 更新所有侧边栏
    QList<SideBarWidget *> allSideBar = SideBarHelper::allSideBar();
    for (SideBarWidget *sidebar : allSideBar)
        sidebar->updateItem(url, info);
    
    return true;
}
```

### 方案四：修改设备挂载流程，让挂载操作变成同步操作（不推荐）

这种方案需要修改设备挂载的底层逻辑，工作量较大，且可能引入新的问题，不建议采用。

### 方案五：使用订阅模式实现双击挂载后自动展开（推荐）

采用订阅模式可以更好地解耦事件的产生和处理，使代码更清晰、更易于维护。具体实现如下：

1. 创建一个设备挂载事件订阅管理类：

```cpp
// 在新文件 utils/devicemountsubscriber.h 中
class DeviceMountSubscriber : public QObject
{
    Q_OBJECT
public:
    // 单例模式
    static DeviceMountSubscriber *instance();
    
    // 订阅挂载完成事件，返回订阅ID
    int subscribe(const QUrl &deviceUrl, std::function<void(const QUrl&)> callback);
    
    // 取消订阅
    void unsubscribe(int subscriptionId);
    
    // 设备挂载完成后调用
    void notifyMountFinished(const QUrl &deviceUrl, const QUrl &mountedUrl);
    
private:
    DeviceMountSubscriber(QObject *parent = nullptr);
    
    struct Subscription {
        int id;
        QUrl deviceUrl;
        std::function<void(const QUrl&)> callback;
        QDateTime timestamp;  // 用于清理长时间未触发的订阅
    };
    
    QMap<int, Subscription> subscriptions;
    int nextSubscriptionId = 0;
    QTimer cleanupTimer;  // 定期清理过期的订阅
    
    void cleanupExpiredSubscriptions();
};
```

2. 实现订阅管理类：

```cpp
// 在新文件 utils/devicemountsubscriber.cpp 中
#include "devicemountsubscriber.h"

DeviceMountSubscriber *DeviceMountSubscriber::instance()
{
    static DeviceMountSubscriber instance;
    return &instance;
}

DeviceMountSubscriber::DeviceMountSubscriber(QObject *parent)
    : QObject(parent)
{
    // 设置定期清理计时器，防止内存泄漏
    connect(&cleanupTimer, &QTimer::timeout, this, &DeviceMountSubscriber::cleanupExpiredSubscriptions);
    cleanupTimer.start(60000);  // 每分钟检查一次
}

int DeviceMountSubscriber::subscribe(const QUrl &deviceUrl, std::function<void(const QUrl&)> callback)
{
    int id = nextSubscriptionId++;
    
    Subscription sub;
    sub.id = id;
    sub.deviceUrl = deviceUrl;
    sub.callback = callback;
    sub.timestamp = QDateTime::currentDateTime();
    
    subscriptions.insert(id, sub);
    
    // 返回订阅ID，可用于取消订阅
    return id;
}

void DeviceMountSubscriber::unsubscribe(int subscriptionId)
{
    subscriptions.remove(subscriptionId);
}

void DeviceMountSubscriber::notifyMountFinished(const QUrl &deviceUrl, const QUrl &mountedUrl)
{
    // 找出所有匹配的订阅并触发回调
    QList<int> matchedIds;
    
    for (auto it = subscriptions.begin(); it != subscriptions.end(); ++it) {
        if (it.value().deviceUrl == deviceUrl) {
            // 执行回调
            it.value().callback(mountedUrl);
            matchedIds.append(it.key());
        }
    }
    
    // 触发后移除这些订阅
    for (int id : matchedIds) {
        subscriptions.remove(id);
    }
}

void DeviceMountSubscriber::cleanupExpiredSubscriptions()
{
    QDateTime now = QDateTime::currentDateTime();
    QList<int> expiredIds;
    
    // 找出超过10分钟的订阅
    for (auto it = subscriptions.begin(); it != subscriptions.end(); ++it) {
        if (it.value().timestamp.secsTo(now) > 600) {  // 10分钟
            expiredIds.append(it.key());
        }
    }
    
    // 移除过期订阅
    for (int id : expiredIds) {
        subscriptions.remove(id);
    }
}
```

3. 修改 `SideBarViewPrivate::onItemDoubleClicked` 方法，使用订阅模式：

```cpp
void SideBarViewPrivate::onItemDoubleClicked(const QModelIndex &index)
{
    if (!index.isValid())
        return;
    
    SideBarItem *item = q->model()->itemFromIndex(index);
    
    // 处理分组项展开/折叠
    if (dynamic_cast<SideBarItemSeparator *>(item)) {
        q->onChangeExpandState(index, !q->isExpanded(index));
        return;
    }
    
    // 处理分区项展开子文件夹
    if (item && item->group() == DefaultGroup::kDevice) {
        // 获取分区路径
        QUrl url = item->targetUrl();
        QUrl originalUrl = item->url();
        
        // 判断设备是否已挂载
        bool deviceMounted = !url.isEmpty() && url.isValid() && 
                            url.scheme() == "file" && 
                            QDir(url.path()).exists();
        
        if (deviceMounted) {
            // 设备已挂载，直接展开
            expandPartitionItem(index, url);
        } else {
            // 设备未挂载，订阅挂载完成事件
            QModelIndex capturedIndex = index;
            
            // 使用弱指针记录当前视图，防止视图被销毁导致崩溃
            QPointer<SideBarView> view = q;
            
            // 订阅挂载完成事件
            DeviceMountSubscriber::instance()->subscribe(
                originalUrl,
                [capturedIndex, view, this](const QUrl &mountedUrl) {
                    // 在挂载完成后展开目录
                    if (!view)
                        return;  // 视图已被销毁
                        
                    // 使用 QTimer 确保在主线程中展开
                    QTimer::singleShot(100, view, [capturedIndex, mountedUrl, view, this]() {
                        if (!view)
                            return;  // 视图已被销毁
                            
                        // 确保 finalUrl 有效且目录存在
                        if (mountedUrl.isValid() && mountedUrl.scheme() == "file" && 
                            QDir(mountedUrl.path()).exists()) {
                            // 展开目录
                            expandPartitionItem(capturedIndex, mountedUrl);
                        }
                    });
                }
            );
            
            // 注意：不需要在这里发送挂载请求，双击事件处理中已经包含挂载的处理逻辑
            // 原有代码会处理设备的挂载操作
        }
        return;
    }
}
```

{
    if (!SideBarInfoCacheMananger::instance()->contains(url))

    for (SideBarWidget *sidebar : allSideBar)
        sidebar->updateItem(url, info);
    
    return true;
}

## 总结

综合考虑，推荐使用方案五（订阅模式），它具有以下优点：

1. 采用订阅-发布模式，更好地解耦事件产生和处理逻辑
2. 无需使用静态变量存储状态，降低代码复杂度和出错可能性
3. 自动处理超时和清理，避免内存泄漏
4. 支持多个订阅者，更具扩展性
5. 代码结构清晰，易于理解和维护
6. 支持视图销毁的安全处理，避免访问已释放的对象
7. 充分利用现有代码，不重复实现挂载请求逻辑

实现这个功能后，用户可以通过双击分区项立即挂载并展开查看目录，无需等待挂载完成后再次点击。通过订阅模式，我们可以优雅地处理这种异步操作之间的依赖关系。
