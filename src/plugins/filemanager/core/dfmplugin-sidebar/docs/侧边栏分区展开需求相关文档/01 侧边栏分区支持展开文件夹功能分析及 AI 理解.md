# 侧边栏分区展开子文件夹功能实现方案

## 需求概述
在侧边栏的"分区"分组中，实现双击分区项展开显示该分区下的文件夹，并且能以树状结构继续展开子文件夹。

## 现状分析
1. 当前侧边栏模块（dfmplugin-sidebar）已实现了树状视图的基本框架，分为三个主要分组：快捷访问、分区、网络。
2. 在 `treeviews` 目录中，`SideBarViewPrivate::onItemDoubleClicked` 方法已实现对分组项（SideBarItemSeparator）的双击处理逻辑，用于折叠/展开分组。
3. 对普通项的双击默认会触发列表视图的双击事件，目前在分区项上双击会触发重命名操作。
4. 重命名功能在 `SideBarItemDelegate` 中的 `createEditor` 方法中实现。

## 实现思路

### 1. 扩展双击事件处理
需要修改 `SideBarViewPrivate::onItemDoubleClicked` 方法，增加对分区项的特殊处理：

```cpp
void SideBarViewPrivate::onItemDoubleClicked(const QModelIndex &index)
{
    if (!index.isValid())
        return;
    
    SideBarItem *item = q->model()->itemFromIndex(index);
    
    // 处理分组项展开/折叠
    if (dynamic_cast<SideBarItemSeparator *>(item)) {
        q->onChangeExpandState(index, !q->isExpanded(index));
        return;
    }
    
    // 新增：处理分区项展开子文件夹
    if (item && item->group() == DefaultGroup::kDevice) {
        // 获取分区路径
        QUrl url = item->finalUrl();
        
        // 判断是否为本地文件路径
        if (url.scheme() != "file")
            return;
            
        // 展开子文件夹
        expandPartitionItem(index, url);
        return;
    }
    
    // 其他项的双击事件保持原有行为
}
```

### 2. 实现文件夹树状展开功能
新增 `expandPartitionItem` 方法，用于加载和显示分区下的文件夹：

```cpp
void SideBarViewPrivate::expandPartitionItem(const QModelIndex &index, const QUrl &url)
{
    // 如果已经展开，则收起
    if (q->isExpanded(index)) {
        q->collapse(index);
        return;
    }
    
    // 清除可能存在的子项
    q->model()->removeRows(0, q->model()->rowCount(index), index);
    
    // 获取目录内容
    QDir dir(url.path());
    dir.setFilter(QDir::Dirs | QDir::NoDotAndDotDot);
    
    // 添加子目录项
    QFileInfoList list = dir.entryInfoList();
    for (const QFileInfo &info : list) {
        QUrl childUrl = QUrl::fromLocalFile(info.absoluteFilePath());
        QIcon icon = QIcon::fromTheme("folder");
        
        // 创建子项
        SideBarItem *childItem = new SideBarItem(icon, 
                                               info.fileName(), 
                                               DefaultGroup::kDevice, 
                                               childUrl);
        childItem->setUrl(childUrl);
        
        // 添加到模型
        q->model()->appendRow(childItem, index);
    }
    
    // 展开当前项
    q->expand(index);
}
```

```cpp

    // 处理分区项
}

// 错误的做法

```

## 实现注意事项
1. 性能考虑：对于文件夹较多的分区，应考虑懒加载或分批加载子文件夹。
2. 内存管理：展开/折叠操作需要确保正确释放资源，避免内存泄漏。
3. 错误处理：处理文件系统权限问题和文件夹读取失败的情况。
4. 展开状态保存：用户关闭文件管理器后，应保存分区项的展开状态。
5. 视觉反馈：提供适当的视觉指示，表明分区项可以展开。
