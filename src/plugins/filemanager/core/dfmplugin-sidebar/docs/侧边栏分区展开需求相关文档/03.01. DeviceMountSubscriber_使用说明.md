# DeviceMountSubscriber 使用说明

## 设计目的

`DeviceMountSubscriber` 类是一个基于发布-订阅模式的设备挂载事件处理组件，旨在解决文件管理器中设备挂载完成后的异步操作问题，特别是解决"双击挂载设备后自动展开目录"的功能需求。

当用户双击侧边栏中的未挂载设备时，系统会执行挂载操作。由于挂载是异步的，传统方法无法直接在挂载完成后立即进行后续操作（如展开目录）。`DeviceMountSubscriber` 通过订阅机制，允许代码在挂载开始前注册一个回调函数，并在挂载完成后自动触发该回调。

## 核心设计

- **单例模式**：确保全局只有一个订阅管理器实例
- **发布-订阅模式**：解耦事件触发和处理逻辑
- **基于 URL 的订阅**：以设备 URL 作为订阅标识
- **超时清理机制**：防止内存泄漏和悬空订阅
- **线程安全设计**：支持多线程环境下的访问

## 主要接口

### 1. 订阅设备挂载完成事件

```cpp
int subscribe(const QUrl &deviceUrl, std::function<void(const QUrl&)> callback);
```

- **参数**：
  - `deviceUrl`: 要监听的设备 URL，如 `device:///dev/sdb1`
  - `callback`: 设备挂载完成后的回调函数，接收挂载点 URL 作为参数
- **返回值**：订阅 ID，用于后续取消订阅
- **使用场景**：在开始挂载设备前调用，注册挂载完成后的处理逻辑

### 2. 通知设备挂载完成

```cpp
void notifyMountFinished(const QUrl &deviceUrl, const QUrl &mountedUrl);
```

- **参数**：
  - `deviceUrl`: 原始设备 URL，与订阅时的 URL 一致
  - `mountedUrl`: 挂载完成后的路径 URL，通常是 `file://` 开头的本地路径
- **使用场景**：在设备挂载完成后调用，触发相关订阅的回调

### 3. 取消订阅

```cpp
void unsubscribe(int subscriptionId);
```

- **参数**：
  - `subscriptionId`: 订阅 ID，由 `subscribe` 方法返回
- **使用场景**：不再需要等待设备挂载完成时调用，取消订阅

## 使用示例

### 1. 双击设备项时订阅挂载完成事件

```cpp
void SideBarViewPrivate::onItemDoubleClicked(const QModelIndex &index)
{
    // ... 其他代码 ...

    // 处理分区项
    if (item && item->group() == DefaultGroup::kDevice) {
        QUrl url = item->targetUrl();
        QUrl originalUrl = item->url();
        
        // 判断设备是否已挂载
        bool deviceMounted = !url.isEmpty() && url.isValid() && 
                             url.scheme() == "file" && 
                             QDir(url.path()).exists();
        
        if (deviceMounted) {
            // 设备已挂载，直接展开
            expandPartitionItem(index, url);
        } else {
            // 设备未挂载，订阅挂载完成事件
            QModelIndex capturedIndex = index;
            QPointer<SideBarView> view = q;
            
            // 订阅挂载完成事件
            DeviceMountSubscriber::instance()->subscribe(
                originalUrl,
                [capturedIndex, view, this](const QUrl &mountedUrl) {
                    if (!view) return;  // 视图已被销毁
                    
                    // 延迟展开，确保目录已完全准备好
                    QTimer::singleShot(100, view, [capturedIndex, mountedUrl, view, this]() {
                        if (!view) return;
                        
                        // 确保挂载点有效且目录存在
                        if (mountedUrl.isValid() && mountedUrl.scheme() == "file" && 
                            QDir(mountedUrl.path()).exists()) {
                            // 展开目录
                            expandPartitionItem(capturedIndex, mountedUrl);
                        }
                    });
                }
            );
            
            // 注意：不需要在这里发送挂载请求，双击事件处理中已经包含挂载的处理逻辑
        }
    }
}
```

### 2. 挂载完成时通知订阅者

```cpp
bool SideBarEventReceiver::handleItemUpdate(const QUrl &url, const QVariantMap &properties)
{
    // ... 获取项信息 ...

    // 处理属性更新
    if (properties.contains(PropertyKey::kFinalUrl)) {
        info.finalUrl = properties[PropertyKey::kFinalUrl].toUrl();
        
        // 如果是设备挂载完成，通知 DeviceMountSubscriber
        if (info.finalUrl.isValid() && info.group == DefaultGroup::kDevice && 
            info.finalUrl.scheme() == "file") {
            // 通知设备挂载订阅者
            DeviceMountSubscriber::instance()->notifyMountFinished(url, info.finalUrl);
        }
    }
    
    // ... 其他处理代码 ...
}
```

## 优点与注意事项

### 优点
- **解耦事件产生和处理**：符合现代事件驱动编程模式
- **无需使用静态变量**：避免全局状态带来的问题
- **自动清理机制**：超时自动移除过期订阅，防止内存泄漏
- **支持多订阅者**：同一设备可以有多个订阅者等待通知
- **安全处理视图销毁**：使用 QPointer 防止访问已销毁对象
- **详细日志**：便于调试和问题追踪

### 注意事项
- 订阅应在发起挂载前完成，否则可能错过通知
- 回调函数中需考虑线程安全问题，避免直接操作 UI 元素
- 建议使用 QTimer::singleShot 延迟执行 UI 相关操作
- 长时间未触发的订阅会被自动清理（10分钟超时）
- 触发回调后订阅会被自动移除，如需再次使用需重新订阅

## 扩展应用

除了侧边栏双击挂载并展开的场景，`DeviceMountSubscriber` 还可用于其他需要在设备挂载完成后执行操作的场景，例如：

1. 挂载后自动打开文件管理器窗口
2. 挂载外接存储设备后执行文件导入操作
3. 挂载后自动执行存储设备上的特定程序
4. 网络驱动器挂载后的自动同步操作

## 后续改进方向
